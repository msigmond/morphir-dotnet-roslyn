# D3 — structured blocks, local state and decisions

Prerequisite: D2 passed. The core lowers Roslyn IOperation with a ControlFlowGraph return-path check and compiler/data-flow scope and definite-assignment validation. Unsupported selected operations are rejected even in unreachable source. Constant-unreachable additions still require an established numeric proof; this is conservative rather than inventing arithmetic semantics.

Block statements become immutable typed LetDefinition bindings and IfThenElse continuations. Local constants, uninitialized declarations later definitely assigned, nested scopes, simple reassignment, early/multiple returns and conditional expressions are admitted. Every assignment gets a fresh deterministic source-derived name (`local_<name>` or `parameter_<name>`, then numbered versions), distinct from parameters/function identities. Nested block locals leave the environment at scope exit; outer rebindings survive. No default value is supplied for an uninitialized local. Every feasible value-return path must return.

Continuation lowering carries each branch's local state into following statements. Nested assignment expressions retain their value and evaluate receivers/operands/call arguments left to right exactly once. Earlier operand snapshots remain immutable after later assignments. Short-circuit and conditional branches run their continuation only on the selected path. Copies of admitted readonly record structs remain independent values after a parameter is rebound. Input member writes, external writes, ref assignments, unknown properties/calls and all unsupported effects fail with source locations.

D1's Int32 arithmetic proof is unchanged: addition requires a constant-safe sum or proved zero operand. Initialized constant local/version values can supply this proof, but a later zero assignment cannot retroactively prove an earlier operand zero. General arithmetic waits for D5. Boolean not, equality/inequality, eager and/or/xor use exact Basics SDK functions; &&/|| remain explicit IfThenElse values. Pure discarded expressions are retained in a binding.

Known-present string returns now include initialized literal locals, branch combinations and already validated closed selected source calls. There are no String parameters/fields, default/null literals or external producers in this closed D3 domain, so origin establishes presence. This removes the old literal-syntax-only check without admitting missing values. D4 owns general M1 String data and presence-flow proofs.

Reference sources are independent: ordinary Elm Category has explicit Int local type annotations (the compiler otherwise leaves generalized local output type variables); the complete Elm codec host extends the frozen D2 algebra with every cumulative D3 function, including unused/private FirstArgument. Expected distributions and provenance are generated only by the pinned Elm compiler/codec, never by adopting frontend output or editing JSON. D1/D2 references remain unchanged. Full structural comparison covers definitions, attributes, local output types, access and array order. Emitted C# behavior independently checks all branches, Int32 extrema, Boolean combinations, local value copies, argument order and assignment snapshots. Negative fixtures check unassigned reads, effects/member mutation and unproved numeric safety; additional tests cover scope, unreachable unknown calls/operators and explicit checked syntax.
