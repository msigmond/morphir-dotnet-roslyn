# D11 — Collections

The user approved this profile on 2026-11-01. The [exact Elm contract](../elm-parity.md) applies.

| C# form | Elm mapping |
| --- | --- |
| One-dimensional arrays; List, sequence, read-only, and immutable list carriers | List |
| Dictionary carriers | Dict |
| Set carriers | Set |
| Explicit elements; dictionary key/value initializers | List literal; Dict.fromList; Set.fromList |
| Collection expressions with spreads | List.concat; Set.toList for a set spread |
| Empty containers | Empty list; Dict.empty; Set.empty |
| Copy/read-only constructors with one source; CreateRange | Same declared carrier, or fromList/toList |
| Immutable Create element overloads; Array.Empty | Explicit elements; empty list |
| Length/Count; IsEmpty | List.length/isEmpty; Dict.size/isEmpty; Set.size/isEmpty |
| Contains/ContainsKey | List.member; Set.member; Dict.member |
| IReadOnlyDictionary Keys/Values | Dict.keys/values |
| List indexing with a declared nullable result | List.head (List.drop index values) |
| Dictionary indexing with a declared nullable result | Dict.get key values |

C#14 can pack factory arguments into an implicit ReadOnlySpan. Only the written elements are mapped.
This does not admit declared spans or other ref-like inputs.
There are no bounds checks, defaults, backing stores, ownership checks, or runtime enumeration machinery.

Multidimensional arrays, size-only arrays, Queue/Stack carriers, capacity/comparer constructors,
mutation, functional update members, ranges, from-end indices, and unlisted members remain rejected.
Literal array lengths with explicit elements map to that List literal.
Computed or named array dimensions cannot retain their written operation and remain rejected.
A source constructor combined with an initializer needs another mapping.
Plain-result indexing, nullable-element indexing that needs flattening, and conditional indexing remain rejected.
Concrete dictionary key/value view types need a separate mapping. The read-only interface views use List.
Spreads require the declared element type. Implicit Set-to-sequence return conversions remain rejected.

Exact case IDs: `d11-lists`, `d11-dict-set`, `d11-types`, and `current-sample`.
