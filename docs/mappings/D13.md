# D13 — Anonymous functions

The user approved this profile on 2026-11-01. The [exact Elm contract](../elm-parity.md) applies.

| C# form | Elm mapping |
| --- | --- |
| Lambda; anonymous method | Curried function with the written parameter names |
| Immutable capture | Lexical reference |
| Explicit Func/Action construction | Function value |
| Delegate invocation; `.Invoke` | Function application |
| Leading lambdas in a definition | Definition inputs, as emitted by the Elm compiler |
| Zero-parameter callback | Result value, under the existing call profile |
| Callback block | Existing let, branch, and return mappings |

Static lambdas need no extra IR node. Generic callbacks keep type variables.
Nullable callback results use the approved Maybe mapping.
The same name and scope checks apply to methods, locals, and callback parameters.
No closure class, receiver snapshot, lifetime state, or runtime proof is added.

Mutation, multicast addition/removal, async/ref callbacks, optional/params callback parameters,
custom delegate declarations, expression trees, and unapproved body operations remain rejected.
An Action body must use an admitted Unit-valued expression or block.

Exact cases: `d13-functions`, `d13-captures`, and `current-sample`.
