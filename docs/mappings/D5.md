# D5 — source structure mapping

Simple numeric operations, source casts and constructors, named constants, and source-domain metadata.

The [source contract](../source-structure.md) controls types, nodes, metadata, and admission.
The [approved audit](../reviews/source-structure-audit.md) records the replaced behavior.
[Migration evidence](../deliveries/source-structure-state.md) records current validation.

- Keep written operations and declared types.
- Keep explicit guards, defaults, casts, arguments, branches, and initializers.
- Do not execute source bodies or insert runtime emulation.
- Require no presence, numeric, ownership, effect, or termination proof.
- Preserve unsupported-form, compiler, selection, and collision diagnostics.
